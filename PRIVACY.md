The extension reads public text elements natively displayed on codeforces.com pages—such as user handles, problem names, difficulty ratings, and algorithmic tags.
This data is processed purely to calculate local training analytics (like the mistake tracker and compare dashboard) and to dynamically inject custom UI enhancements (like user notes and dark mode).
All data reading and rendering happen 100% locally on the user's device. No user activity, web content, or telemetry is ever collected, stored remotely, or transmitted to external servers.
